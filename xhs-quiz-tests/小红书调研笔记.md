# 小红书「职业 / 性格测试」调研笔记

> Lauren，先说清楚这份笔记的局限。

## 0. 这次调研实际做到了什么（如实说明）

- **没能直接浏览小红书。** 我运行在云端容器里，不在你的电脑上。这个环境的网络策略拦截了 `xiaohongshu.com`：浏览器打开报 `ERR_TUNNEL_CONNECTION_FAILED`，网页抓取工具解析不到域名。所以没有出现登录墙或扫码页，是在请求网络这一步就被拦了。我也**没有**输入任何账号密码，没有点赞、评论或关注。
- **目标是 40+ 篇，实际直接读到的是 0 篇。** 我能拿到的只有搜索引擎索引里的小红书笔记**标题和摘要**，以及站外的报道和行业分析文章。**点赞、收藏数一个都没拿到**。下表里凡是数字，都标明了出处；没有出处的地方，我没有自己估一个数填进去。
- **想补上这一块，有两条路：**
  1. 在会话标题栏打开环境菜单 → Edit → Network access，把 `xiaohongshu.com`（以及图片域名 `xhscdn.com`）加入 Allowed domains（[说明](https://code.claude.com/docs/en/cloud-environments#network-access)）。即使这样，小红书多半还会弹登录墙，而云端浏览器你没法直接扫码。
  2. 更现实的做法：在 Claude 桌面端用 Claude in Chrome 或内置浏览器，这样走的是你自己已登录的小红书。我可以按第 4 节的记录模板慢速浏览、只读不互动。

## 2. 站外资料：测试为什么会火

**SBTI（2026 年 4 月刷屏）**，只分析机制，不借用它的任何内容：
- 31 道题左右，约 5 分钟做完；结果页包括人格代号、**匹配度百分比**、雷达图和文案，方便截图转发。匹配方式是把用户的多维得分和人格模板比对，取最接近的，匹配度过低时还有兜底结果；另有**隐藏结果**，选中特定选项才会触发。（[开源复刻项目说明](https://github.com/aaronyang-ai/sbti-test)、[介绍页](https://ai-bot.cn/sbti-test/)；各站对题数和人格数的说法有出入）
- 爆火原因，媒体的归纳大致是：标签反差、自嘲，用荒诞的词说出真心话；门槛低、结果截图本身就是社交货币；对 MBTI 的“挑衅式”定位；服务器挤崩之后，“只能看截图”反而制造了稀缺感。（[腾讯新闻](https://news.qq.com/rain/a/20260410A02NTD00)、[光明网](https://m.gmw.cn/2026-04/10/content_1304412972.htm)、[网易](https://m.163.com/dy/article/KQ6312DP05118O92.html)、[新浪财经](https://finance.sina.com.cn/wm/2026-04-10/doc-inhtyrvy1324226.shtml)）
- 争议：缺乏科学依据；作者本人也承认部分人格的解释比较模糊，并道歉。→ 我们的**免责声明 + 不宣称科学**是必须的。

**网易系测试 H5（人格主导色等）**：
- 有分析认为，测试类内容的共性是：与“我”有关所以愿意转发、制作成本低、题材借经典心理学背书、结果偏正面便于展示身份标签；同时案例里也有**被平台以“多人投诉”为由停止访问**的风险。（[数英](https://www.digitaling.com/articles/457624.html)、[知乎](https://zhuanlan.zhihu.com/p/378850552)、[人人都是产品经理](http://www.woshipm.com/operate/4612631.html)、[腾讯云社区](https://cloud.tencent.com/developer/article/1427863)）

**小红书心理测试账号的变现和风险**：
- 有副业类文章提到：心理测试图文号先用低价资料引流，再导到私域卖高价测评；也有案例称用 AI 做心理测试图文号，十几天就接到商单。（[搜狐](https://m.sohu.com/a/964087777_122565465)、[知乎](https://zhuanlan.zhihu.com/p/693445564)；属营销类文章，数据未经核实）
- **平台风险**：“私我发链接”“回复某个词领福利”这类暗号式导流、多账号互相导流，都被列为违规，可能被限流或封号。（[人人都是产品经理 · 防封号指南](https://www.woshipm.com/share/6458166.html)）→ 所以我把四套测试都设计成**图文内直接答题、站内闭环**，正文话术里不出现任何导流暗号。

**题目来源的合规性**：
- IPIP 题库属公共领域，无需授权（[Wikipedia](https://en.wikipedia.org/wiki/International_Personality_Item_Pool)）。不过我们的题目全部是原创情景题，只借用了“五个维度”的思路，没有直接翻译 IPIP 的原题。

## 3. 由调研推导出的设计规则（已落实到四套测试）

| 规则 | 依据 | 落实方式 |
|---|---|---|
| 结果标签自带梗、有反差 | SBTI 分析 | 画饼发射器、明天的我会处理、表面平静湖…… |
| 一句能直接发朋友圈的话 | 你的调研 + 截图分享机制 | 每个结果一句 ≤24 字的金句，校验脚本会检查字数 |
| 戳小毛病比夸奖更容易传播 | 你的调研 + SBTI 自嘲 | 每个结果 3 条“戳你一下”，再接 1 条“其实你很会”，戳完再安抚 |
| 匹配度百分比 | SBTI 结果页 | 四套都有公式透明、可以手算的匹配度 |
| 隐藏结果 | SBTI 的隐藏触发 | 六边形打工人、双核打工人、出厂设置未拆封 |
| ≤30 题、几分钟做完 | SBTI 约 31 题、约 5 分钟 | 12～25 题，1.5～4.5 分钟 |
| 社交钩子 | H5 转发逻辑 | 搭子 / 相克、“转给那个总说没事的朋友” |
| 站内闭环、不靠外链 | 小红书导流规则 | 文字版直接放在图文轮播里，最后一页对答案 |
| 不宣称科学、加免责声明 | SBTI 争议、平台投诉风险 | 每套测试的开头和结尾各放一次；校验脚本扫“科学测”“准到”“注定”等词 |
