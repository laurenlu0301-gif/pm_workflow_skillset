# 小红书文字版测试 · 交付包

| 文件 | 内容 |
|---|---|
| `测试文字版.md` | **主交付**：4 套测试（2 套职业 + 2 套性格），每套包括标题备选、封面钩子、正文话术、题目、计分规则、结果文案和分享卡模板 |
| `校验报告.md` | 自动校验结果：全部答案组合的精确分布、可达性、模拟答题人、文档规则对拍、题量与时长、合规扫描 |
| `小红书调研笔记.md` | 调研记录（含局限说明）和由此推导出的设计规则 |
| `quizdata.py` | 题目和文案的唯一数据源，改文案只改这里 |
| `engine.py` | 计分引擎 |
| `build_doc.py` | 由数据生成 `测试文字版.md` |
| `validate.py` | 生成 `校验报告.md` |

修改文案后重新生成和校验（校验约 10 分钟，主要耗时在测试 3 的精确枚举）：

```bash
python3 build_doc.py && python3 validate.py
```
